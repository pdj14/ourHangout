# Renewal Concept

## One-Line Concept

Our Hangout is a private place for families and close friends to keep daily conversations reliable, calm, and easy to return to.

## Positioning

This app should not compete as a full KakaoTalk, LINE, Telegram, or Discord replacement. Its defensible position is narrower:

- close-circle chat
- family room identity
- clear consent for safety features
- low-noise, polished daily use

## MVP Principle

Chat reliability comes first.

The first release should prove:

- session restore is predictable
- room lists load quickly
- messages appear instantly
- realtime updates do not fight polling
- push opens the correct room
- family features never slow down chat

## Feature Priority

### Keep

- Google/login session
- friends and family contacts
- 1:1 rooms
- group rooms
- family rooms
- text chat
- photo chat after text is stable
- push notification
- family location request with explicit consent

### Remove From MVP

- OpenClaw
- bot/device pairing
- hidden server menu
- app update installer UI
- heavy hideout/custom room systems
- mock auto-replies in production flow

## Navigation

Recommended tabs:

- Chats
- People
- Family
- Me

The default screen should be Chats, not a marketing page.

## Design Direction

The visual system should feel mature and warm:

- light neutral surface
- ink-like text
- teal and blue for trust
- coral only for human warmth or alerts
- compact cards with clear hierarchy
- restrained shadows
- no decorative clutter
